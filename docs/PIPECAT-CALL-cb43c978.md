В основной части максимальная пауза между подтверждённым окончанием ответа агента и началом следующей речи клиента — около 1,31 с. Приоритет следующих изменений:

1. Исключить повторно закоммиченную речь из pre-roll; отдельно от эксперимента с обрезанием накопленной тишины. Сохранять нужный незакоммиченный onset при раннем перебивании. Регрессия: commit короткой реплики → поздняя финальная STT → interruption → отсутствие прежней реплики в следующем input item.
2. Согласовывать и валидировать весь набор фактов визита одной операцией с исходными цитатами; сохранять день при его появлении. Не ослаблять валидацию «завтра» цитатой «всё верно». Удерживать речь в фазе подтверждения/завершения и на служебных продолжениях после инструментов до принятия решения; не задерживать весь обычный диалог.
3. Логировать пустой completed response отдельно и спроектировать ограниченное восстановление для явного первого обращения, сохраняя молчание на IVR/ожидании. Проверить конфликт waiting_for_person с первым ответом до финальной STT.
4. Отдельно проверить случаи Smart Turn INCOMPLETE на коротких законченных репликах и времена удержания кадров TTS/инструментов. Не менять VAD-пороги на основании одного звонка.

В этой итерации изменён только отчёт; настройки работающего звонкового сервиса не менялись.
