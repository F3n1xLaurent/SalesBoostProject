# Единая запись тренировки

После завершения тренировки запись собирается **параллельно** с оценкой. Ошибка
конвертации не блокирует отчёт и не меняет оценку. Старые завершённые тренировки
без записи ставятся в очередь при открытии отчёта. Повторная генерация TTS не нужна.

Исходники: сохранённые `transcriptJson[*].audioBase64`, в исходном порядке. WAV,
OGG/Opus и поддерживаемые MP3/M4A приводятся к mono 24 kHz; выход — MP3 96 kbps.
Между репликами 300 мс тишины. Реальные интервалы ожидания/генерации не
восстанавливаются; это явно обозначено в плеере. Аудио внутри отдельных реплик
не обрезается. Если любой исходник отсутствует или повреждён, сборка завершается
ошибкой, а не публикует неполную запись.

Файлы находятся в `CALL_RECORDINGS_DIR/trainers/<sessionId>/`: `recording.mp3` и
`state.json`. Этот каталог должен находиться на постоянном томе, как и записи
звонков. Исходные реплики и данные отчёта не изменяются. Публикация атомарная;
FFmpeg обрабатывает одну тренировку за раз, максимум 200 реплик/100 MiB входных
данных, с тайм-аутом 120 секунд. Временные исходники удаляются после конвертации.
После перезапуска незавершённая сборка возобновляется при обращении к отчёту.

## FFmpeg

Docker устанавливает системный FFmpeg. При локальной обычной `npm install` пакет
`ffmpeg-static` скачивает платформенный бинарник. После `npm ci --ignore-scripts`
его можно установить командой `node node_modules/ffmpeg-static/install.js` либо
использовать системный FFmpeg. `FFMPEG_PATH` позволяет указать собственный путь.
Аудио не отправляется во внешние сервисы.

## Проверка и старые тренировки

```sh
node --import tsx scripts/build-trainer-recording.ts <sessionId>
```

Готовая запись повторно не создаётся. Явный запуск скрипта может повторить
неудачную сборку; чтение отчёта автоматически не зацикливает failed-задачи.
Скрипт выводит путь и фактическую длительность результата и не запускает оценку.

## Доступ

`GET /api/admin/trainer-recordings/:sessionId` — прослушивание,
`.../download` — скачивание, `.../status` — состояние/автопостановка в очередь.
Все три используют авторизацию и ту же область доступа, что отчёт тренировки:
сотрудник видит только собственные сессии; администраторы — свою компанию/точку.
Записи звонков и ограничения их скачивания не изменены.
