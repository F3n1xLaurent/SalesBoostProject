# Pipecat: проверенные оптимизации разговора

13 ноября 2026. Изолированная гипотеза `/testing`, runtime `pipecat-conversation-3`. Production voice pipeline не менялся. OpenAI Realtime 2.1 Mini, reasoning `low`, собственный TTS и server VAD OpenAI выключены; ElevenLabs v4 turbo, PCM16 mono 16 kHz.

## Что включено

- На пользовательскую реплику разрешены максимум шесть вызовов инструментов и две ошибки. После повторной ошибки автоматические попытки прекращаются; backend задаёт один уточняющий вопрос. Вопрос сохраняется как последний услышанный только после playback ACK. Поздний результат старого инструмента не расходует бюджет новой реплики. Одно VAD-срабатывание на подтверждение не снимает блокировку.
- `fast_sentence`: SpeechFilter по-прежнему проверяет текст и выпускает законченное предложение. ElevenLabs получает его без повторного накопления предложения в Pipecat; первое предложение контекста сопровождается flush. Слова и обрывки фраз отдельно не отправляются.
- При частичной транскрипции перебивания, начинающейся со «стоп», «подождите», «постойте», используется ранняя отмена. Старые транскрипции, «угу» и слова вроде «стопор» эту ветку не включают. Её реальная скорость зависит от прихода частичной STT, поэтому фиксированные 400 мс не обещаются.
- В сценарий Voximplant добавлены ping/pong и удалённые метки воспроизведения. Измеряются RTT, оценка смещения часов и её неопределённость. `audio_sent → callback` не объявляется чистой задержкой буфера. Метрики появятся в следующем настоящем звонке.

## Замеры

Использованы синтетические тексты, без телефонных звонков и CRM. Медианы разных этапов нельзя складывать или выдавать за итоговую задержку разговора.

| Проверка | Прежний режим | Кандидат | Решение |
|---|---:|---:|---|
| Реальный ElevenLabs, первый текст → первое аудио, по 5 попыток | sentence: 545.89 мс | fast_sentence: 374.19 мс | Включён fast_sentence |
| Реальный Mini, первый текст, 10 сценариев на профиль | legacy: 726.11 мс | compact: 749.67 мс | Оставлен legacy |
| Контрольные WebSocket ping/pong, по 5 проб | OpenAI: 191.66 мс | ElevenLabs: 71.74 мс | Только транспорт, без inference |

TTS: одинаковый голос и текст, имитация поступления текста по 8 символов каждые 40 мс, заранее открытый сокет. Все 10 попыток дали настоящее аудио; полный нормализованный текст на отправке провайдеру совпал. Выигрыш 171.70 мс относится к этому этапу на данном тексте. WAV сохранены, но сравнительная оценка интонации на слух не выполнена; записи не идентичны побайтово.

Ограничитель: 21 намеренно некорректная попытка дала только две бизнес-проверки и один вопрос «Подтвердите, пожалуйста: завтра, в одиннадцать?». Реальный TTS, 102400 байт аудио, вопрос сохранён после имитированного playback ACK; факты не выдуманы, завершение звонка не запрошено. Транспорт Vox в пробе имитирован.

Промпт: два сценария (визит и перезвон), по пять повторов каждого на профиль, 20 диалогов. Бизнес-критерий выполнен в 7/10 случаев у каждого профиля. Compact сократил тестовый промпт с 3825 до 2041 символа, но ускорения не показал и в одном завершённом сценарии сохранил время перезвона без «завтра». Legacy в одном завершённом сценарии не сохранил перезвон. По два случая каждого профиля завершились таймаутом текстового стенда после исчерпания бюджета: уточняющий вопрос был сформирован, а стенд ошибочно ожидал автоматического продолжения инструментов. Условие ожидания стенда исправлено после замера; исходные результаты сохранены без переоценки и повторов до успеха. Эти результаты не подтверждают надёжность всех бизнес-сценариев или улучшение естественности. Compact доступен для отдельных скриптов, в звонках не включён.

Пороги перебивания проверены отдельно на настоящем таймере TurnMonitor, но с искусственными VAD-событиями, без Silero/STT: 45 проб, по пять на сочетание длительности и порога. При порогах 400/600 мс длительное «угу» 750 мс обрывалось в 5/10 подтверждений; при 850 мс — 0/10. Для полноценной речи остановка срабатывала через медианные 603/803/1052 мс от VAD-start, включая существующую поправку 200 мс. Это проверка логики длительности, а не оценка распознавания реальной речи. Поэтому общий порог оставлен 850 мс.

## Настройки и проверка

По умолчанию `PIPECAT_SPEECH_MODE=fast_sentence`, `PIPECAT_INTERRUPTION_MS=850`, промпт legacy. Для возврата прежней подачи TTS: прописать `PIPECAT_SPEECH_MODE=sentence` в корневой `.env` и выполнить `npm run pipecat:up`. Значения 400/600 допустимы только как экспериментальные пороги; защита медленного «угу» ими не гарантируется.

104 локальных Python-теста проходят: бюджеты и поздние результаты, уточнение и продолжение после него, ранняя отмена, выпуск проверенного текста, nonce/RTT и существующие проверки очередей/завершения. Это дополняет реальные API-пробы, а не заменяет звонок.

После окончательной пересборки health подтвердил `fast_sentence`, порог 850 и legacy. Повторная проба обрыва Realtime прошла: `pc-e5e0a222-fbfd-4eab-8406-ab9452ad5054`, 153600 байт реального ElevenLabs-аудио, одна попытка отправки в потерянный сокет, завершение после имитированного ACK, ноль телефонных звонков. Проверки синтаксиса Vox JavaScript и `git diff --check` прошли.

Артефакты (ignored storage): `storage/pipecat-benchmarks/conversation-3/provider-reports.json`; таймеры — `storage/pipecat-benchmarks/pbi-bec6a973-4a0b-4a67-8169-c2db05ba0b29.json`. В Docker исходные отчёты: `pta-78b0e322-c859-4024-bb88-a2a5f6ce06bc`, `ppp-19cc83d4-81ae-45a9-8f50-eefb1bdd2aec`, `pnr-a99a683d-4148-442c-82cd-b3ef7e2302db` в `/data/logs`.

Сценарий обновлён только для `voice_pipecat_hypothesis` (3788384), правило 9686731, SHA256 `8176a300dbd132570b02756f4d0cdab22294c5dc78ad5cb77317da700dcb5170`.

Следующий настоящий звонок нужен для оценки интонации, конца речи → слышимого ответа, RTT Vox, остановки голоса при перебивании и восстановления контекста после паузы. Сквозная медиана 1.5 секунды этой итерацией пока не подтверждена. Ошибки Mini при сохранении перезвона остаются известным ограничением; быстрый TTS их не исправляет.
