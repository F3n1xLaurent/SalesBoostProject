# Вдох не слышен · ecbc06b2

Эксперимент был включён. Вдох сконфигурирован как WAV 640 мс, volume=0,18.

Два запроса дошли до Voximplant: плеер сообщил started/ended в 49,16–50,12 с и 77,38–78,31 с от начала сессии. Для первого stop_breath пришёл уже после ended, для второго — практически одновременно с ended. Ранней отмены речи менеджером нет. Эти события не доказывают, что звук слышен абоненту.

Измерение PCM показало недостаточный уровень относительно постоянного фона. Телефонная полоса ниже моделируется фильтром 300–3400 Гц; это расчёт по файлам, не запись исходящего телефонного канала.

| Файл | RMS, дБFS | RMS в модели телефонной полосы, дБFS |
| --- | ---: | ---: |
| Фон звонка | −38,8 | −43,0 |
| Прежний вдох | −43,2 | −47,3 |
| Нормализованный вдох | −28,9 | −33,0 |

Уровень подготовленных голосовых реплик этого звонка — примерно −17 дБFS RMS. Новая версия вдоха остаётся примерно на 12 дБ тише голоса, но оказывается примерно на 10 дБ выше среднего фона в модели телефонной полосы. Маскирование фоном — вероятное объяснение неслышимости; подтвердить субъективную слышимость может только следующий звонок/прослушивание.

Исправление: перед применением громкости нормализовать источник к фиксированному RMS-ориентиру и ограничить выходной пик. Для текущего файла итоговое усиление составляет около 14,3 дБ относительно прежней версии, пик −13,8 дБFS, без клиппинга. Таймер, частота, отдельный плеер, сохранение вдоха при речи менеджера и остановка при готовности голоса ИИ остаются прежними.

Файл нового эффекта имеет новый хеш `125428ca37e8d4a19a1d19cbdb85c79990830b2b862a293055af0d0aae09280a.wav`. В диагностике добавлены `normalization=rms-v2` и `rms_dbfs`.
