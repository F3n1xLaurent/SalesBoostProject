# Фон для звонков Pipecat

Положите сюда готовые WAV, MP3, OGG, FLAC, M4A, AAC или OPUS файлы (не в подпапки). Один случайный файл выбирается на каждый новый звонок. Файл повторяется целиком до завершения звонка, также во время речи и перебиваний. Пустая папка означает звонок без фона.

Громкость по умолчанию — 20% исходной амплитуды. Настройка в корневом `.env`: `PIPECAT_BACKGROUND_VOLUME=0.2`; отключение: `PIPECAT_BACKGROUND_ENABLED=false`. После изменения `.env`: `npm run pipecat:up`. Добавление или замена файлов не требует перезапуска: папка подключена к Docker напрямую.

Сервис заранее преобразует выбранный файл в WAV PCM16, mono, 16 кГц с нужной громкостью. Лимит результата — 10 МБ (примерно пять минут); исходного файла — 100 МиБ. Для длинных записей используйте короткий фрагмент. Неудачный файл пропускается с записью в диагностику.

Фон играет отдельным URLPlayer Voximplant через конференцию вместе с речью агента. Входящий звук человека идёт напрямую в Pipecat. Фон не участвует в VAD, очереди TTS или условиях завершения звонка.

Аудиофайлы игнорируются Git. Для production эту же папку нужно положить на сервер рядом с compose-файлом.
